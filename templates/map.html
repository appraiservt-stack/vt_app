VT Property Transfer Tool

Search Tips ×
  1. The sales database starts on January 1, 2019 through present date. On startup transfers are loaded into the map window.
  2. The map displays up to 2,000 records. As the map is zoomed in more records populate in the window area.
  3. If the user hovers over a property a popup window will show the sale history.
  4. The user can select whichever search criteria they desire by selecting or unselecting checkboxes.
  5. The default setting includes $0 sales, such as family transfers, corrective deeds, etc. Setting $1 in the Sale Price eliminates them.
  6. The user can download all filtered sales or sales selected from the map selections using the two download buttons.
  7. Clicking on a search heading opens the search box. Clicking it again closes the search box.
  8. Filtering by County(s) and/or Town(s) is recommended to be enabled before other refinement filters are set.
  9. Immediately above the Location heading the display shows X sales at X properties. The second number is how many sales are in the current window. If the first number is more than the second number this indicates some of the properties have more than one transaction during the date range. This will identify sale/resale properties.
  10. The default startup for the map loads all sales and checks all possible property selection options.
  11. As selection options are enabled or disabled the Apply Filters button can be clicked at any time to update the search criteria.
  12. NEIGHBORHOOD COMPARISON: The polygon, circle, or box can be used to highlight different neighborhoods on the same map at the same time. The map will calculate the High, Low, Average, Median, and count of sales in each selection. $0 are not included in the calculations. Filtering applies to the entire map, not individual polygons, boxes, or circles. If you select Single Family Homes, for example, all highlighted areas will contain only Single Family Homes.
